# ai-gtm-command-center
AI-native account research and account planning workflow for strategic sellers

## Interview & Discovery Simulator

This repo includes a lightweight browser module that helps strategic AEs
practice selling Cursor-like AI developer tools to technical, executive,
security, and procurement buyers.

### What it includes

- Role-play simulator with buyer questions and objections
- Buyer persona selection
- Scenario selection
- Competitive objection handling
- Color-coded 1-5 scorecard
- Coaching feedback with a stronger answer example
- Save results locally in the browser
- Export a simulation result as JSON

### Run it

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

### Included personas

CTO, CIO, VP Engineering, Head of Developer Productivity, Platform Engineering
Leader, Staff Engineer, Engineering Manager, CISO, Head of AppSec, Security
Architect, Procurement, CFO, Skeptical developer, Existing Copilot power user,
CLI-native engineer using Claude Code or Codex, and Enterprise buyer evaluating
Windsurf or Devin.

### Included scenarios

First discovery call, Technical evaluation, Security review, Executive business
case, Competitive displacement, Pilot design, Deal review, and Tree House-style
interview simulation.
